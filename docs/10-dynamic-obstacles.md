# 10. 新しく現れた障害物を避ける

確認日: 2026-11-12

## 仕組み

保存済みの `maps/my_map.yaml` は、SLAM 時点の壁や物を記録した地図。Nav2 は走行中の `/scan` も読み、**コストマップ**に新しく見つけた障害物を追加する。コストマップは、通行可能な場所、危険な場所、通れない場所を経路計画・制御のために表す一時的な地図。

このフォルダの [Waffle 設定](../config/waffle_nav2.yaml) では、ローカルとグローバルのコストマップに `ObstacleLayer`、`VoxelLayer`、`InflationLayer` があり、グローバル側には保存地図を読む `StaticLayer` もある。両コストマップの障害物レイヤーは `/scan` を入力とし、`marking: true` で検出物を追加、`clearing: true` でレーザーが空間を通過した場所を消去する。障害物の周囲には `InflationLayer` が余裕を設ける。

この Waffle のレーザーは、前方に反射物がないと `inf` を返す。インストール済みの TurtleBot3 設定は、これを消去用の測定として扱う `inf_is_valid` が未設定（既定値 `false`）。実測では箱を削除してもコストマップに障害物が残ったため、ワークスペース側設定のローカル／グローバルの `ObstacleLayer` と `VoxelLayer` の `/scan` に `inf_is_valid: true` を追加した。

新しい物を取り除いても、保存済みの PGM/YAML は書き換わらない。センサーが空いた場所を再観測すると動的な障害物情報がコストマップから消え、経路が再計画され得る。RViz で見えるコストマップの変化と保存地図そのものの変化は区別する。

## Gazebo Harmonic での実習

1. [08. 保存済み地図でナビゲーション](08-navigation-world.md) の手順で TurtleBot3 World と Nav2 を起動し、**2D Pose Estimate** で現在位置を合わせる。
2. Gazebo の画面上部にある基本形状の **Box** ボタンで箱を追加する。Gazebo Classic の動画にあるコーヒーテーブルをダウンロードする必要はない。ロボットの進行を妨げる位置に置くが、ロボット本体には重ねない。
3. 箱の高さが LiDAR の走査面（この Waffle では床から約 `0.121 m`）を横切ることを確認する。位置を調整する場合は Gazebo の移動ツールを使う。
4. RViz の **Nav2 Goal** で箱の向こう側の走行可能地点を指定する。必要なら Gazebo 下部の **Play/Pause** で時間を止め、配置後に再開する。
5. RViz のレーザースキャン、ローカル／グローバルコストマップ、計画経路と、Gazebo での実際の動きを見比べる。別の通路があれば迂回し得る。通路が塞がっていれば停止や目標失敗も正常な結果。
6. Gazebo で箱を右クリックして **Remove** し、センサーが元の場所を再観測した後、コストマップと経路の変化を確認する。

## 見落としやすい点

- 2D LiDAR は走査面と交わる物体を検出する。床に近い脚だけ、走査面より上の板だけなどは見逃す場合がある。動画のテーブルのように一部だけ検出すると、実物の輪郭とコストマップが一致しない。
- 障害物が見えても必ず迂回できるわけではない。幅、ロボットの半径、障害物との余裕、別経路の有無で決まる。
- 障害物にぶつかってロボットが傾くと、レーザーの向きや自己位置推定が乱れ得る。RViz の表示が崩れたときは停止し、Gazebo の位置と初期位置推定を確認する。

## この PC での実測

Gazebo Harmonic の TurtleBot3 World に高さ `0.6 m` の箱を一時追加し、削除した。場所は `(-1.3, -0.5)`、ロボットの初期位置は `(-2.0, -0.5)`。箱の SDF と測定スクリプトは `/tmp` の一時ファイルで、ワークスペースには追加していない。

| 状態 | 前方 LiDAR | 箱の位置のグローバルコストマップ値 |
| --- | --- | ---: |
| 箱なし | `inf`（反射なし） | `32` |
| 箱あり | 約 `0.65 m` | `99` |
| 箱を削除、元の設定 | `inf` | `99` が残った |
| 箱を削除、`inf_is_valid: true` | `inf` | `32` に戻った |

これは**検出と消去の検証**。障害物の周りを走って目標地点に到達する実走は、この回では未検証。
